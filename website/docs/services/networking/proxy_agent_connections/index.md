Returns all connections attached to the specified proxy agent within your Fivetran account.

```sql
SELECT
connection_id
FROM fivetran.networking.proxy_agent_connections
WHERE agent_id = '{{ agent_id }}' -- required
AND "limit" = '{{ limit }}'
;
```
